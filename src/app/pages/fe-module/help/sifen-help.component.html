Como probar

Guia humana de uso

Recorrido corto para validar dashboard, diagnostico, facturas e integracion sin tocar backend.

  1. SuperAdmin: login, Companias, crear compania, abrir detalle, editar plan, crear admin, cargar configuracion, correr diagnostico.
  2. SuperAdmin: desde detalle de compania, entrar a Operacion FE del tenant.
  3. TenantAdmin: login, revisar dashboard, entrar a Operacion FE, emitir TipoDoc 01, abrir detalle, descargar XML/KuDE.
  4. Integracion API: abrir panel Integracion, copiar endpoints, revisar ejemplo JSON y checklist.
  5. Antes de SIFEN test real: confirmar diagnostico, ambiente, transporte y credenciales reales.
